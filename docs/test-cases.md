# 테스트 시나리오

"테스트 먼저" 작업용 명세다. 각 행을 pytest 테스트 하나로 만든다. AI가 들어가는 테스트는 모두 `FakeBackend`를 쓰고, 실제 호출은 하지 않는다. 모든 테스트는 `XHUMAN_HOME`을 임시 폴더로 둔다.

| ID | 시나리오 | 기대 결과 |
