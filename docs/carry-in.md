# 반입 점검 (11/10 규정 확인 반영)

주최 측 답변(11/10 기준, 구두): **프로토타입 코드는 반입 불가. 시연용 사내 데이터와 기획 문서(md)는 가능할 것으로 보임.** 일정: 구현은 목 08~22시, 필요하면 금 08~13시. 발표자료는 목요일 22시 이후 집에서 만들 수 있음. "가능할 것 같다"는 확정이 아니므로 4장 질문으로 서면 확인을 받는다.

## 1. 판단 기준

이 문서에서 "코드"는 **복사해서 그대로 실행하거나 붙여 넣으면 제품의 일부가 되는 것**으로 본다. 같은 결과를 얻으려면 당일 다시 구현해야 하는 수준의 규칙 설명, 입출력 형식, 화면 문구는 기획 문서로 본다. 주최 측 기준이 더 엄격하면(예: 단어 목록이나 JSON 예시도 불가) 4장 질문 3의 답에 맞춰 다시 줄인다.

점검 방법: 모든 md의 코드 블록을 언어 표시별로 나열해 하나씩 봤고, `def `·`class `·`import `·`re.compile`·정규식 기호를 검색했다. 위 표 외에는 해당 없음.

## 4. 주최 측에 추가로 확인할 질문 (최종 7개, 11/10 발송본)

**11/11 답변:** 질문 4는 대화 기록과 샘플 코드 **둘 다 가능**. 11/11 22시까지 GitHub로 전달한다(아래 6장). 문서(지시문·프롬프트 포함)도 그대로 가져가는 것으로 확인했다(질문 1·2). 질문 3은 발표자료를 미리 만들어도 됨. 장표는 해커톤 PC로 가져가지 않고 목요일 22시 이후 집에서 따로 다듬는다. 질문 5·6: 금요일 코딩은 13시까지, 발표자료 마감 14시, 발표는 14시부터 순서대로. 질문 7: Claude·Codex 계정은 개인 계정이 아니라 주최 측이 새로 나눠 주고, `pip install`은 가능. 7개 모두 답을 받았다.

**기획서**

1. **문서의 상세 수준:** 기획 문서(md)에 DB 테이블 컬럼 표, AI 출력 JSON 형식 예시, 처리 규칙을 문장으로 쓴 설명(판정 순서, 단어 목록 등)을 넣어도 되나요? 코드, 정규식 원문, 함수 본문은 넣지 않았습니다.
2. **문서 안의 AI 작업 지시문:** 당일 AI 코딩 도구에 입력할 단계별 작업 지시문과 AI 프롬프트(자연어)를 문서에 넣어 가져가도 되나요?
3. **발표자료 사전 준비:** 발표 문안이나 슬라이드 틀을 미리 만들어 두어도 되나요?

**시연 데이터**

4. **대화 기록과 샘플 코드:** 사전에 녹화한 Claude Code 대화 기록(JSONL)과, 그 대화에서 AI가 만든 결제 예제 코드(Python 약 300줄, 테스트 포함)를 시연용 데이터로 가져가도 되나요? 둘 중 하나만 된다면 어느 쪽인가요?

**일정·환경**

5. **금요일 일정:** 발표 시작 시각과 순서, 발표자료 제출 마감은 언제인가요?
6. **금요일 오전 코딩:** 금요일 08~13시에도 코드를 수정할 수 있나요?
7. **환경:** 개인 Claude 계정 로그인과 `pip install`(pytest 등)을 해커톤 PC에서 해도 되나요?

질문 4가 가장 중요하다. 안 되면 시연 데이터를 목요일에 새로 만들어야 한다(5장). 질문 5·6이 금요일 최종 동결 시각(build-plan 1.2)을 정한다. 사전 AI 응답·분석 결과는 묻지 않고 반입하지 않기로 했다. 문서만으로 재구현해 보는 사전 연습도 묻지 않았으므로 하지 않는다.
